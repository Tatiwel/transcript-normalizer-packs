# Um nome é tratado como palavra comum quando cada palavra dele, dobrada como a engine
# dobra (minúsculas, sem acento), está nesta lista, entre as palavras comuns do módulo
# pt-BR da engine, ou tem uma letra só. "Banco do Brasil" é palavra comum; "Banco
# Bradesco" não é. Um nome comum ganha contexto (D-086). Um apelido de uma palavra só
# que seja comum não entra, e uma linha que começa com `=` exclui um apelido inteiro.

# Desde que os termos gerados casam só por igualdade (`match: exact`, D-090), a lista
# não tem mais os nomes que o fuzzy levaria a uma palavra comum (Energisa, Multiplan…):
# sem fuzzy, esse risco não existe.

# e apelidos marcados `conferido` e `usar_no_pack=sim`. Uma linha por palavra, já dobrada.
# O que vem depois de `#` é comentário.
